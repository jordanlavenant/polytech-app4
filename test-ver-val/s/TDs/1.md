## Spécification d'un algorithme de tri

### 1

On spécifie le programme `trier`, comme suit :

Le programme prend en entrée un tableau d'entier.

Le programme renvoie le tableau trié par ordre croissant.

Le tableau en sortie contient les mêmes valeurs que le tableau en entrée, avec le même nombre d'occurences.

### 2

On spécifie le programme `trier`, comme suit :

Le programme prend en entrée un tableau $t$ d'entier.

Et renvoie un tableau $z$ tel que : $z[i] <= z[i+1]$, pour tout $i \in [0, lg(z) - 1]$, avec $lg = longueur$.

**ou**

Pour tout $i,j \in [0, lg(z) -1]$, avec $i \le j$, $z[i] \le z[j]$.

Et, pour tout $i \in [0, lg(t) -1]$, $occ(t[i], t) = occ(t[i], z)$, avec $occ = occurences$

> On compte les occurences de la valeur du tableau d'entrée $t[i]$, dans le tableau d'entrée $t$ et de sortie $z$

Et, pour tout $i \in [0, lg(z) -1]$, $occ(z[i], t) == occ(z[i], z)$

> On vérifie que les occurences de la valeur du tableau de sortie $z[i]$, dans le tableau d'entrée $t$ et $z$

### 3

| Objectif        | Entree            | Resultat attendu  |
| --------------- | ----------------- | ----------------- |
| Vide            | `[]`              | `[]`              |
| Déjà trié       | `[1, 2, 3, 4]`    | `[1, 2, 3, 4]`    |
| Non trié        | `[6, 0, 9, 8]`    | `[0, 6, 8, 9]`    |
| Avec répétition | `[3, 5, 3, 3, 0]` | `[0, 3, 3, 3, 5]` |
| Décroissant     | `[2, 1, 0]`       | `[0, 1, 2]`       |
