# Perfect CV

## Advices

- No photo
- No age
- No birthdate
- No address
- No mariage status
- Optimized for ATS
  - Get passed the robot
  - Get human attention in under 6s
- Perfect structure
  - Contact details
  - Professionnal summary
    - What you are
    - What you do
    - What you looking for
  - Work experience
  - Education
  - Skills
  - Certification (optional)
- Add numbers, percentage, stats

## Mistakes

- Unusual design CV (keep it simple)
- Using generic CV (each CV should be tailored for the offer)
- Focusing on responsabilities instead of accomplishements

## ATS pass

- Proper keyword research (requirement, qualification, skills)
- Use standard headings
- Save CV as a PDF file
- Keep the file name professionnal (name-CV.pdf)

## AI

- How well you can use this AI
- Mastering prompting (specify as much information as possible of the offer for help improving CV)
